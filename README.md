# ShelfGuide - Dashboard chef de rayon

Dashboard web autonome pour Vercel.

## Variables Vercel

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
- `VITE_STORE_NAME` optionnel, pour limiter au magasin du chef de rayon
- `VITE_CATEGORY` optionnel, pour limiter a une categorie

## Deploy Vercel

Dans Vercel, choisis ce dossier comme Root Directory: `dashboard-chef-rayon`.

Build command: `npm run build`

Output directory: `dist`
